# 데이터 운영 데모 요구사항

합성 주문을 검색·편집하고 같은 데이터의 요약·그래프를 확인하는 메모리 기반 데모다. 데모·요구사항·설계·테스트 설계의 네 탭을 제공한다. 실제 검증 결과는 실행 로그에서 확인한다.

포트폴리오에 표시하는 세 언어의 요구사항 원본은 `content/data-operations-messages.ts`의 `requirements`다. 공개 화면은 `/{locale}/lab/data-operations-demo`이며 비공개 초안을 런타임에 읽지 않는다.

## 기능과 테스트의 연결

| 요구사항 | 내용 | 완료 기준 |
| --- | --- | --- |
| F01 | 고정 합성 주문 샘플 | A01 |
| F02 | 검색·기간·상태·카테고리 필터 | A03·A04·A05 |
| F03 | 목록·상세 진입·날짜와 금액 정렬 | A04·A09 |
| F04 | 금액·상태 편집과 취소 | A02·A05·A09 |
| F05 | 저장 전 입력 검증 | A05 |
| F06 | 주문 수·완료 수·완료 매출 요약 | A01·A03·A07 |
| F07 | 날짜별 매출 선 그래프 | A01·A04·A07·A09 |
| F08 | 카테고리별 매출 막대 그래프 | A01·A04·A07·A09 |
| F09 | 저장과 표·요약·그래프 동시 반영 | A02·A06 |
| F10 | 원본 샘플과 화면 상태 초기화 | A08 |

완료 기준 A01~A09의 입력·기대 결과는 [테스트 설계](TEST-DESIGN.md)에 있다. 구조와 대안 선택의 이유는 [설계](DESIGN.md)에 있다. 테스트 계획과 현재 실행 결과를 구분한다.

## 공통 규칙

첫 탭은 데모다. 문서 탭 왕복은 주문·필터·편집 초안을 유지한다. 새로고침·언어 이동·샘플 초기화는 원본으로 복원한다. 필터 초기화는 저장한 수정을 유지한다. 필터 입력은 초안이며 적용 버튼을 눌러 반영한다. 적용은 열린 편집 초안을 폐기한다.

금액은 0~1,000,000엔의 정수다. 잘못된 저장은 원본을 바꾸지 않는다. 매출은 필터 결과 중 완료 주문 금액 합계이며 미저장 초안은 집계하지 않는다. Recharts 선·막대와 동일한 값의 HTML 집계 표를 제공한다. 백엔드·DB·인증·영구 저장·외부 쓰기는 제외한다.
