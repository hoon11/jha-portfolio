# 공조 모니터링 콘셉트 테스트 설계

작성일: 2026-10-18 JST. [요구사항](REQUIREMENTS.md)과 [설계](DESIGN.md)를 검증하기 위한 항목이다. 이 문서는 통과 기록이 아니다. 실행 여부와 관찰 결과는 별도 검증 기록으로 구분한다.

## 자동 테스트 대상

| ID | 연결 요구사항 | 조작·입력 | 기대 결과 |
| --- | --- | --- | --- |
| T01 | M01, M02 | 최초 표시 후 단면도와 목록에서 각각 다른 기기를 선택 | 초기 AC-101, 이후 모든 선택 표시와 상세가 같은 ID를 사용한다. |
| T02 | M01, Q03 | 같은 기기를 반복 선택하고 포커스 확인 | 선택이 해제되지 않고 aria-pressed를 유지하며 포커스를 빼앗지 않는다. |
| T03 | M04, Q01 | AC-301 선택 | 운전 중은 유지하고 13:00의 마지막 수신값 27.0°C와 이전 데이터 안내를 표시한다. |
| T04 | M03, Q02 | 고정 fixture와 null 표시 입력 확인 | 매시 9개 지점과 AC-301의 12:00·14:00 null을 유지하며 미수신을 0°C로 표시하지 않는다. |
| T05 | L02, Q04 | 미리보기 선택 후 문서 탭 전환·복귀 | 작은 카드가 선택한 공간·운전·온도를 표시하고 복귀 후 선택을 유지한다. |

선택 테스트는 사용자에게 보이는 결과와 접근 가능한 버튼 상태를 확인한다. 내부 컴포넌트 구조만 복제하는 테스트는 만들지 않는다. 차트의 실제 시각적인 빈 구간은 DOM 속성 확인만으로 완료 처리하지 않는다.

## 브라우저 확인 대상

| ID | 연결 요구사항 | 조작·입력 | 기대 결과 |
| --- | --- | --- | --- |
| T06 | L01–L03 | 첫 CTA·마지막 CTA·데모의 돌아가기 링크 | 별도 모니터링 데모와 소개 페이지로 정확히 이동한다. 랜딩에는 전체 목록과 온도 추이를 넣지 않는다. |
| T07 | M03, Q02 | AC-301의 차트와 값 표 확인 | 값과 시각·단위가 같고 12:00·14:00 미수신을 임의로 연결하거나 채우지 않는다. |
| T08 | Q03, Q04 | 키보드 선택·문서 탭·3언어·1280/1024/768/390/320px | 포커스와 선택이 구분되고 조작부·텍스트가 겹치지 않는다. 각 언어의 데이터 사실이 같다. |
| T09 | Q04 | 재읽기·언어 변경·페이지 이동 | 초기 AC-101로 돌아간다. 명시적으로 스크롤하는 표 외에 가로 넘침이 없다. |

## 회귀와 공개 경계

기존 API Rescue Lab과 주문 데모의 테스트·타입 검사·프로덕션 빌드를 실행한다. 정적 언어 경로·메타데이터·공통 내비게이션이 새 경로에서도 동작하는지 확인한다. 공개 diff와 빌드 결과에 비공개 문서·실제 브랜드·실제 고객 데이터·새로운 경력 주장이 들어가지 않았는지 점검한다.

자동 검증으로 증명한 사실과 실제 브라우저에서 확인한 화면을 분리해 기록한다. 실제 센서 정확도·고장 탐지·설비 제어·에너지 절감은 검증 대상이 아니며 관련 성과를 주장하지 않는다.
