## 공개 경계와 한계

고정 샘플·설명용 단면도·마지막 수신값을 명시한다. 실제 업체·건물·고객 데이터, 실기기 연결·제어·저장·자동 고장 판정은 없다. 비공개 기획 자료는 Git 제외 상태다.

`npm audit --omit=dev`는 기존 간접 의존성 source-map-js 1.2.1에 high 1건(GHSA-68fv-2mgg-jv7q)을 보고했다. 이번 기능은 의존성을 변경하지 않았으며 이 경고도 해결하지 않았다. 테스트·빌드 통과를 보안 경고 해소로 해석하지 않는다.

jsdom은 실제 레이아웃을 계산하지 않으므로 자동 테스트의 ResizeObserver 대체는 차트 크기의 증거가 아니다. 크기와 미수신 선 끊김은 위 브라우저 확인으로 구분했다. 모든 OS·보조기기·화면 조합을 검증했다는 의미는 아니다.
