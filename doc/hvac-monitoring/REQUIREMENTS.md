# 공조 모니터링 콘셉트 요구사항

작성일: 2026-10-18 JST. 개인 프런트엔드 콘셉트의 의도한 동작을 정의한다. 실제 제품·고객 사례·설비 운영의 증거가 아니다.

## 페이지와 범위

- `/{locale}/lab/hvac-monitoring`: 서비스 소개. 단면도 미리보기, 간단한 선택 정보, 세 가지 특징, 사용 흐름, 별도 데모 CTA를 제공한다.
- `/{locale}/lab/hvac-monitoring/demo`: 읽기 전용 모니터링. 단면도·전체 기기 목록·상세·실내 온도 추이·값 표를 제공한다.
- 소개 페이지의 네 탭에서 서비스 소개·요구사항·설계·테스트 설계를 읽는다. 문서 전환으로 미리보기 선택을 초기화하지 않는다.
- 영어·일본어·한국어의 경로와 사실은 동일하다. 샘플 건물 1개, 3개 층, 3대의 공조기를 사용한다.

## 기능 계약

| ID | 요구사항 |
| --- | --- |
| L01 | 첫 화면에서 서비스 목적과 별도 모니터링 데모로 이동하는 CTA를 제공한다. |
| L02 | 설명용 건물 단면도의 기기를 선택하면 공간·운전 상태·실내 온도를 간결하게 표시한다. 이전 데이터인 경우 이를 설명한다. |
| L03 | 위치 파악·상태 확인·온도 추이의 세 특징과 건물→기기→상세 흐름을 소개하고 마지막 CTA로 데모를 연다. |
| M01 | 데모의 단면도와 목록은 하나의 선택 ID를 공유한다. 초기 선택은 AC-101이며 반복 선택으로 해제하지 않는다. |
| M02 | 선택 기기의 ID·공간·운전 상태·실내 온도·설정 온도·마지막 수신 시각·데이터 갱신 상태를 표시한다. |
| M03 | 선택 기기의 06:00~14:00 매시 실내 온도 추이를 °C 단위로 표시하고 동일한 값 표를 제공한다. |
| M04 | 기준 시점을 2026-09-15 14:00 JST로 고정하고 실제 현재 시각이나 자동 갱신처럼 표시하지 않는다. |
| Q01 | 운전과 갱신 상태를 분리한다. 이전 데이터가 고장·정지·건강 위험을 뜻하지 않는다. |
| Q02 | 미수신은 null로 유지한다. 0°C로 대체하거나 그래프의 빈 구간을 연결하지 않는다. |
| Q03 | 기기 선택에 네이티브 버튼·키보드 조작·보이는 포커스·글자 상태를 제공한다. 선택만으로 포커스를 옮기지 않는다. |
| Q04 | 세 언어와 320px 이상 화면을 지원한다. 새로고침·언어 변경·페이지 이동은 초기 선택으로 돌아간다. |

## 샘플 데이터

| 기기 | 층·공간 | 운전 | 마지막 실내 온도 | 설정 온도 | 마지막 수신 |
| --- | --- | --- | --- | --- | --- |
| AC-101 | 1층 라운지 | 운전 중 | 24.5°C | 24.0°C | 14:00 JST |
| AC-201 | 2층 회의실 | 정지 | 26.0°C | 26.0°C | 14:00 JST |
| AC-301 | 3층 업무공간 | 운전 중 | 27.0°C | 25.0°C | 13:00 JST |

모든 시각은 샘플 날짜 기준이다. AC-301은 마지막 수신 당시의 상태와 온도를 보여준다. 12:00와 14:00 추이 값은 null이며 13:00의 27.0°C가 마지막 수신값이다. 온도와 설정값의 차이로 자동 경고나 고장을 판정하지 않는다.

## 제외 범위

실제 설비·제조사 연동, 실제 건물·고객 데이터, 전원·모드·온도 제어, 로그인, DB, 영구 저장, 알림, 신청·결제, 3D·줌·도면 편집은 포함하지 않는다. 고객 로고·후기·절감 성과를 만들지 않는다. 목록은 3대 전체를 제공하며 검색·필터·정렬을 추가하지 않는다.
